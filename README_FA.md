# مینی‌اپ مدیریت کارگرهای کلش

## امکانات
- ثبت چند اکانت
- ثبت زمان باقی‌مانده ارتقای هر کارگر
- ارسال پیام تلگرام پس از پایان زمان

## پیش‌نیاز
- Node.js 18 یا جدیدتر
- توکن ربات تلگرام در متغیر محیطی `BOT_TOKEN`

## اجرای محلی
```bash
npm install
BOT_TOKEN=توکن_ربات npm start
```

## نکات مهم
1. کاربر باید ابتدا به ربات در تلگرام پیام `/start` بدهد تا ربات بتواند پیام خصوصی بفرستد.
2. در BotFather آدرس HTTPS برنامه را به‌عنوان Mini App تنظیم کنید.
3. در حال حاضر زمان ارتقا به‌صورت دستی وارد می‌شود؛ برنامه به بازی Clash of Clans وصل نیست.
4. سرور باید همیشه در حال اجرا باشد تا اعلان‌ها به‌موقع ارسال شوند.
5. ذخیره‌سازی فعلی در `data.json` است. روی هاست‌هایی که فایل‌ها را پاک می‌کنند پایدار نیست؛ برای استفاده دائمی باید دیتابیس پایدار متصل شود.
6. توکن ربات را هرگز داخل کد یا مخزن عمومی قرار ندهید؛ فقط در Environment Variables هاست وارد کنید.
