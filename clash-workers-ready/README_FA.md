# ربات Clash Workers

برنامه وب تلگرام برای ثبت دستی زمان ارتقای سازنده‌ها در چند اکانت کلش اف کلنز.

## راه‌اندازی
- نیازمند Node.js نسخه 18 یا بالاتر است.
- دستور اجرا: `npm start`
- متغیر محیطی `BOT_TOKEN` را با توکن ربات تلگرام تنظیم کنید.
- کاربر باید ابتدا ربات را در تلگرام با دستور `/start` فعال کند تا ربات بتواند پیام خصوصی بفرستد.

## نکته‌ها
- زمان‌ها به‌صورت دستی وارد می‌شوند؛ این برنامه اطلاعات بازی را خودکار از سرورهای کلش دریافت نمی‌کند.
- داده‌ها در `data.json` ذخیره می‌شوند. روی هاست‌هایی که فضای ذخیره‌سازی موقت دارند ممکن است اطلاعات پس از راه‌اندازی مجدد پاک شود؛ برای استفاده پایدار، فضای ذخیره‌سازی دائمی یا دیتابیس لازم است.
- توکن ربات را هرگز داخل فایل‌های پروژه یا مخزن عمومی قرار ندهید؛ فقط در بخش Environment Variables هاست وارد کنید.
